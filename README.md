# Class_Fin_Big_Data
一、课程基本信息
课程名称：金融大数据分析
授课对象：研究生
授课教师：许泳昊（金融学院）
教师联系方式：
Email：xuyonghao@zuel.edu.cn
课程核心定位：聚焦金融领域大数据的理论、技术与应用，培养数据处理、分析及可视化能力，助力解决金融实际问题。
二、课程核心内容
核心模块：
基础能力：数据收集（爬虫：静态 / 动态网页）、数据读取（数值 / 文本 / 图像型数据）；
分析技术：文本分析（词典法、主题分类）、图像识别（人脸情绪识别等）、数据降维、图像识别、因果 / 预测分析（回归、神经网络等）；
可视化应用：常见图（直方图、折线图）、动态图、热力图、词云图、社交网络图，含 Python 工具实操（如 matplotlib、Pandas_Alive）
学习要求：
完成课堂展示（presentation）与期末大作业（小组合作，≤4 人）；
三、课程目标
帮助学生掌握金融大数据的核心理论，熟练运用数据获取、分析及可视化工具，能将技术应用于金融场景（如资产定价、公司金融分析），具备解决金融领域数据驱动问题的基础能力。
